# Proyecto: Viaje a Pereira

## Descripción
Landing page estática para planear un viaje a Pereira, Colombia. Incluye información de vuelos LATAM, mapa de ubicación y puntos de interés del Eje Cafetero.

## Stack
- HTML + CSS puro (sin frameworks)
- Sin dependencias externas (máximo Google Fonts)
- Despliegue en Vercel (static site)

## Estructura del proyecto
```
/
├── index.html          # Página principal
├── imagen-mapa.png     # Mapa de Colombia con Pereira
├── Vuelos latam.png    # Captura de vuelos LATAM
├── CLAUDE.md           # Este archivo
└── README.md           # Descripción del repo
```

## Datos del viaje
- **Ruta**: Cartagena de Indias (CTG) ↔ Pereira (PEI)
- **Aerolínea**: LATAM Airlines Colombia
- **Ida**: Jueves 18 de junio — 9:25 a.m. → 1:00 p.m. (1 parada, 3h 35min) — COP 236.758/pasajero
- **Regreso**: Domingo 21 de junio — 6:55 p.m. → 11:35 p.m. (1 parada, 4h 40min) — COP 243.282/pasajero
- **Tarifa**: Basic (sin reembolso, incluye bolso de mano)
- **Duración del viaje**: 3 noches (18–21 junio)

## Convenciones
- Responder siempre en español
- Diseño limpio, moderno, inspirado en la región cafetera (colores tierra, verde, café)
- Imágenes locales referenciadas por nombre exacto (con espacios tal cual están)
- No usar JavaScript innecesario

## Git & Vercel
- Repositorio GitHub conectado a Vercel para auto-deploy en cada push a main
- El archivo `index.html` en la raíz es el entry point
